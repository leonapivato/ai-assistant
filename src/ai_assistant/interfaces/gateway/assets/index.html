Every session ends when the gateway process does. A session is held in that process's memory and written down nowhere, so a gateway that starts again has no memory of this one.

A session also ends on its own: at gateway_session_ttl from when it started, and after gateway_session_idle_timeout with no request the gateway admitted. Watching for notifications is not such a request, so a page left open and asked nothing expires on time.

Closing the browser may end it and may not — that depends on a setting of your browser's that the gateway cannot see. Either way the way back is a fresh bootstrap value, minted at the machine the gateway runs on.
